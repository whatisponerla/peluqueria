# FEATURES

## Versión 0.1
- Reserva de turnos por QR/Enlace.
- Gestión de clientes por teléfono.
- Consulta de horarios disponibles con selector de fecha.
- Administración de horarios (Vista Turnos Aprobados, Sin Aprobar y Crear Turno).
- LocalStorage para autocompletado en el cliente.
- Arquitectura React + Express + MySQL.

## Versión 0.2
- Reserva de turnos con selección de servicio, fecha y horario.
- Confirmación con resumen de reserva; precio pendiente de definición y sin cobro integrado.
- Panel de administración con agenda del día, aprobación/rechazo de solicitudes y creación manual de turnos.
- Calendario mensual responsive con horarios disponibles.

## Futuras funcionalidades
Solo agregar mediante aprobación y registro:
- WhatsApp.
- MercadoPago.
- Recordatorios.
- Estadísticas.
- Reportes.
